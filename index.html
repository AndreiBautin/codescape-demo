A screensaver for your source code

Your codebase,
as a 1998 screensaver.

Point Codescape at any public GitHub repo and watch it grow as glossy 3D pipes, fly past as a starfield, or ribbon across the screen like Mystify — rebuilt with a modern glass UI. Free, installable, no server, no sign-in.

live · Codescape rendering its own repo

Three screensavers, one tree

The repo is parsed into a folder tree once; each mode is a different way of drawing it.

3D Pipes

A pipe per top-level folder, a branch per subfolder, a joint per file.

Starfield

Every file is a star, coloured by language, brighter the more lines it has.

Mystify

The biggest folders become bouncing polygons; size sets their speed.

Point it at any public repo

Paste owner/name or a GitHub URL.

facebook/react microsoft/vscode torvalds/linux python/cpython rust-lang/rust

Install it like an app

In Chrome or Edge, open Codescape and click the install icon in the address bar (or ⋮ → Cast, save and share → Install). It gets its own window and desktop icon, and opens offline.

Controls

  • 1 2 3 switch modes · Space pause
  • F fullscreen · R reshuffle · O open a local folder
  • Hover any joint, star or ribbon to see the file or folder it represents
  • Local folders are read in your browser and never uploaded
